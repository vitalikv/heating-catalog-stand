# Журнал расхождений с gl2

Каждое осознанное отличие библиотеки от старого проекта `gl2` (`3d-stroyka/gl2`): что, где, почему.
Записи перенесены 19 октября 2026 из раздела 12 [development-plan.md](development-plan.md) без изменений;
новые записи добавляются в конец таблицы. Как проводится сверка — [gl2-verification.md](gl2-verification.md).

Имена в записях — из `gl2`: ID функций (`st_mufta_1`), ключи `cdm` (`r1`, `m1`, `side`) и пункты
старых планов (контракт п. 4, план переноса). Соответствие новым ID и параметрам —
[library-refactoring-plan.md](library-refactoring-plan.md), п. 3. Записи о новых моделях вне `gl2` сюда не входят:
их отличия от изделий-ориентиров — в карточках [catalog-expansion-plan.md](catalog-expansion-plan.md).
